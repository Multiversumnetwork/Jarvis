# Changelog

## 2026-05-12

Initiale Projektstruktur für JARVIS Home erstellt.

Festgelegt:

- JARVIS ist Haussteuerung, nicht Pepper
- Home Assistant OS auf offizieller Nabu-Casa-Hardware
- Home Assistant Voice Preview Edition
- ESP32-S3-BOX-3 als Satelliten
- Küche mit Android-Tablet
- Apple Home bleibt für Manon via HomeKit Bridge
- OpenRouter als LLM-Anbindung
- Grocy für Vorratsverwaltung
- altes Android-Handy als mobiles Vorrats-Terminal
- Android zuerst, LineageOS nur optional
- UniFi Protect als geplante Kamera-Plattform
- Drohnen als späteres separates Sicherheitsprojekt
- GitOps- und Change-Request-Prinzip
