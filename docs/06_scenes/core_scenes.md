# Kern-Szenen

## Ziel

JARVIS soll nicht nur Geräte schalten, sondern Alltagssituationen verstehen.

## Szene: Guten Morgen

Ziel:

- Haus sanft aktivieren
- Bad und Wohnbereich vorbereiten
- Manon-Komfort berücksichtigen
- Wetter und Kalender einbeziehen

Mögliche Aktionen:

- Badheizung hochfahren
- Warmwasser prüfen
- sanftes Licht aktivieren
- Wetterhinweis geben
- Kalenderhinweise nennen
- Kaffeemaschine vorbereiten, falls erlaubt

Beispielantwort:

```text
Guten Morgen. Das Bad wird aufgeheizt, draußen sind es vier Grad. Ich würde heute die dickere Jacke empfehlen.
```

## Szene: Manon Komfort

Ziel:

- kalte Füße vermeiden
- Bad rechtzeitig warm
- Dusche komfortabel
- minimale Bedienkomplexität

Trigger:

- Uhrzeit
- Kalender
- Anwesenheit
- Wochentag
- Außentemperatur

## Szene: Nachtmodus

Aktionen:

- Lichter ausschalten
- Türen/Fenster prüfen
- Heizung absenken
- kritische Geräte prüfen
- Kameramodus später aktivieren

Beispielantwort:

```text
Nachtmodus ist vorbereitet. Das Garagentor ist geschlossen, alle relevanten Fenster sind zu.
```

## Szene: Abwesenheit

Aktionen:

- Licht aus
- Heizung reduzieren
- unnötige Verbraucher aus
- Sicherheitsstatus prüfen
- Kameras später aktivieren

## Szene: Filmabend

Aktionen:

- Wohnzimmerlicht dimmen
- indirektes Licht aktivieren
- ggf. Jellyfin/Multiversum Cinema vorbereiten
- Störungen reduzieren

## Szene: Arbeit

Aktionen:

- Bürolicht anpassen
- Temperatur setzen
- Benachrichtigungen reduzieren
- Fokusmodus optional
