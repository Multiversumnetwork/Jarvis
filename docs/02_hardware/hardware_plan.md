# Hardwareplan

## Zentrale

### Home Assistant Green

Start mit offizieller Nabu-Casa-Hardware.

Gründe:

- einfach
- stabil
- offiziell unterstützt
- Home Assistant OS vorinstalliert
- idealer Einstieg ohne VM-Komplexität

## Voice

### Home Assistant Voice Preview Edition

Funktion:

- Spracheingabe
- Wake Word
- Home Assistant Assist
- lokaler Betrieb soweit möglich
- Basisgerät für JARVIS-Sprache

## Satelliten

### ESP32-S3-BOX-3

Geplante Nutzung:

- kleine flexible Satelliten
- Mini-Display
- Sprachinteraktion
- Raumstatus
- JARVIS-Visualisierung
- spätere eigene UI via ESPHome/LVGL

Einsatzorte:

- Wohnzimmer
- Büro
- Schlafzimmer
- Waschküche optional
- Garage/Werkstatt später

## Küche

### Android-Tablet

Geplante Nutzung:

- JARVIS Hauptdashboard
- Kalender
- Wetter
- Kamerafeeds
- Szenen
- Energie
- Garten
- Vorräte
- Haushaltsstatus

Mögliche Software:

- Home Assistant Companion App
- Browser/Kiosk-Modus
- Fully Kiosk Browser

## Vorräte

### Altes Android-Handy

Geplante Nutzung:

- Grocy Vorrats-Terminal
- Barcode-Scanning per Kamera
- Einkaufsliste
- Mindestbestände
- mobile Nutzung direkt am Regal

Hardware-Idee:

- altes Android-Handy
- Magnethalterung am Metallregal
- Ladepunkt in der Waschküche
- optional robuste Hülle

## Kameras

### UniFi Protect

Geplante Nutzung:

- Außenkameras
- Innenkamera optional
- Doorbell optional
- Kamera-Feeds im JARVIS-Dashboard
- Ereignisbasierte Benachrichtigungen

## Drohnen

Späteres Subprojekt.

Geplant:

- Indoor-Drohne
- Outdoor-Drohne
- Sicherheitszonen
- manuelle Freigabe
- keine unbeaufsichtigte Risikonavigation
